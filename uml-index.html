UML (Unified Modeling Language)

UML on standardiseeritud modelleerimiskeel tarkvarasüsteemide visualiseerimiseks ja dokumenteerimiseks. Seda kasutatakse süsteemide struktuuri ja käitumise kirjeldamiseks. UML aitab arendajatel ja analüütikutel paremini suhelda.

Alamlehed

ERD Diagrammid Vooskeem / Activity Diagram

Diagrammide kirjeldused

Use Case Diagram

Kasutusjuhtude diagramm kirjeldab süsteemi funktsionaalsust kasutaja vaatenurgast. See näitab, kuidas kasutajad süsteemiga suhtlevad.

  • Actor – kasutaja
  • Use case – tegevus (ovaal)
  • Seos – joon

Class Diagram

Klassidiagramm näitab süsteemi klasse, nende atribuute ja meetodeid ning seoseid. See on objektorienteeritud süsteemide alus.

  • Klass – ristkülik
  • Atribuudid
  • Meetodid

Sequence Diagram

Järjestusdiagramm näitab objektide vahelist suhtlust ajas. See keskendub sõnumite järjekorrale.

  • Objektid
  • Sõnumid (nooled)

State Diagram

Oleku diagramm kirjeldab objekti olekuid ja nende muutusi. Seda kasutatakse süsteemi käitumise modelleerimiseks.

  • Olek – ring
  • Üleminek – nool

Component Diagram

Komponentdiagramm näitab süsteemi komponente ja nendevahelisi sõltuvusi. Seda kasutatakse arhitektuuri visualiseerimiseks.

  • Komponent – ristkülik
  • Seosed
